# 路线图（Roadmap）

> 按优先级排列；标注 [P0/P1/P2] 表示核心程度，[易/中/难] 为实现成本。
> 欢迎按条目认领贡献；条目编号供 issue 引用（如 `R3`）。

## R1 高度轴分区块（Y 分片加载）[P0·中]

**现状**：加载粒度是整个区块列（16×384×16），即使镜头只在地表活动，
也会把 ymin~ymax 全高拉下来。

**方案**：把调度 key 从 `(dim, cx, cz)` 扩展为 `(dim, cx, cz, sy)`
（sy = Y 段索引，每段 4~8 个 Section）：

- 调度器需求集扩展为 2.5D 圆盘（XZ 半径 × Y 段范围，Y 范围随镜头高度滑动）；
- 卸载判定对 Y 段独立做迟滞（镜头爬升时下方段逐步卸载）；
- MCC1/MCM1 协议已按 Section 对齐（presentMask + yBottom），协议基本兼容，
  只需允许插件按段请求（服务端按段裁剪 payload）；
- 存档模式天然支持（sections 本来就是独立的）；
- 预期收益：地表动画场景内存/首载时间再降 50–80%。

**验收**：俯冲镜头从 y=200 降到 y=60，空中段自动卸载、无接缝。

## R2 原版材质/模型烘焙（客户端资产提取）[P0·中]

**现状**：贴图靠服务端 `mcbridge/textures/` 手工放置或程序化色块；
楼梯/栅栏等 class5 方块以完整方块近似，观感穿帮。

**方案**：新增「资产烘焙」工具链，从 **MC 客户端 jar / 资源包** 一次性提取：

1. **贴图烘焙**：解析 `assets/minecraft/textures/block/*.png` +
   方块状态→模型→贴图映射（`blockstates/*.json` → `models/block/*.json`），
   按「方块 × 面组」输出 16×16 PNG 包（含染色图，如草/叶的灰度 + tint 色）；
2. **模型烘焙**：解析原版方块模型 JSON（elements/from/to/faces/uv/rotation），
   把 class5 方块（楼梯/台阶/围栏/门/玻璃板…）烘焙成四边形流（含真实 UV），
   按「方块状态 → 几何」缓存为二进制资产包；
3. **分发格式**：单文件资产包（zip 或自定义 `MCBA1` 二进制），
   插件按 palette 名查找；服务端模式由模组打包下发，存档模式本地加载；
4. **染色**：草/叶/水保留 tint 顶点色管线（现有 `Col` 节点不变）。

**验收**：楼梯显示真实阶梯形状；草侧贴图带泥土过渡；栅栏为十字栏杆。

## R3 模组材质/模型烘焙 [P1·中]

R2 的推广：对**模组方块**同样生效。

- 模组方块模型注册走同一套 vanilla 格式（blockstates/models JSON），
  烘焙工具扫 `mods/*.jar` 内的 `assets/<ns>/` 即可覆盖；
- 遮挡分类：无法从 JSON 判定的（如动态形状），提供 `mcbridge-classes.json`
  手工标注表 + 启发式（模型占空比 < 0.85 判为 NONCUBE）；
- 风险：模组可用动态 BlockState/BakedModel 代码（非 JSON），
  该部分回退到完整方块近似并在导出清单中标记。

## R4 跨区块贪心合并 [P1·中]

**现状**：合并范围限单区块内（跨区块收益 <2%），区块边界处可见接缝面。

**方案**：调度器按 2×2 / 4×4 区块组拉取，网格器在组内合并；
主要收益是**对象数减少 4–16 倍**（draw call 下降），而非减面。

## R5 实体与方块实体 [P2·难]

箱子/告示牌/盔甲架/画等以代理占位（简化盒 + 标签）；
作物生长等方块实体状态（`block_entities` NBT）驱动贴图变体。
存档模式可直接读 NBT；控制模式需模组扩展 API。

## R6 渲染增强 [P2·易~中]

- 水面 UV 滚动动画（节点实现，贴图 offset 随帧）；
- 发光方块（萤石/岩浆）输出自发光节点（Emission × 原版 light 值）；
- 光照烘焙：从存档 `LightEngine` 数据（sky/block light NBT）导出顶点光照，
  替代 EEVEE 环境光遮蔽的近似；
- 雾/远景：Distant Horizons 风格的多级高度壳（复用 LOD2 路径生成金字塔）。

## R7 稳定性与生态 [P1·易]

- 插件多版本 MC 模组适配层（1.20/1.21 映射差异收敛到模组内薄适配）；
- `load_post` 残留对象处理（提示转静态或清除，当前仅有手动卸载）；
- 进度条 UI（预热/首载时显示区块 x/y）；
- 国际化（面板文案 en/zh）；
- CI：GitHub Actions 跑 pytest + Java 对拍 + 打包发布（zip/jar artifact）。
