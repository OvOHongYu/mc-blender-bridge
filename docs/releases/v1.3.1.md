# v1.3.1 群系染色（R8）+ 模组方块实机修复

> 本版重点：R8 群系染色落地、模组方块（任意 `mods/*.jar`）实机可用性修复、
> 移除 LOD 分层与烘焙 AO、贪心网格器提速。

## 新增

- **R8 群系染色**：草/叶/水按所在**群系**取原版色（colormap 公式与沼泽/黑森林
  modifier 对齐原版字节码）；资产包 v6 携带群系色表；存档模式走 Anvil 群系
  调色板，控制模式新增 **MCC1 v2**（Section 级 4×4×4 群系）；面板新增
  「按群系调色」开关；A/B 两条路径观感与面数一致。
- **模组方块通用支持**：`bake_assets.py` 把 `mods/*.jar` 一并传入即可
  （自动扫描命名空间，形状/贴图/分类/染色全通用）——Ultramarine 518 方块
  实测通过。

## 修复

- **面遮挡判据**：改用原版 `isOpaqueFullCube`（= 原版面剔除同口径），修复
  非整方块（箱子/雪层/花盆/模组装饰…）邻居面被错误剔除导致的"缺面/空洞"；
  此前用反射按 Yarn 名探测，发布包重映射后必然失效。
- **模型元素级 rotation 三处错误**（对照原版字节码）：角度符号镜像、
  `rescale` 未实现、`int(round(22.5))` 舍入成 22°——凳子部件散架、斜瓦
  填满整格的根因。blockstate 级旋转（负角）与元素级（正角）符号约定分开处理。
- **状态属性序列化名**：改用原版 `Property.name(value)`，修复模组自定义枚举
  属性（如 `snow_side=NONE`）导致变体解析落空、方块整方块化。
- **含水炼药锅**不再误判为流体（`instanceof FluidBlock` 精确判定）。
- 顶点色 sRGB→线性、叠加层材质合成（草方块侧草皮与顶面一致）等 v1.3.0
  之后的累计修复一并包含。

## 变更

- **移除 LOD 分层**（用户决策）：所有距离统一满质量网格，消除远处方块化与
  拉近重建的闪变；面板不再有 LOD 距离项（协议保留 lod 参数）。
- **不再烘焙 AO**（用户决策）：光照（含环境光遮蔽）交给 Blender 自身；
  合并键少一个维度，网格化更快。
- **性能**：流体几何只计算液体邻域（138ms → 3ms/组）；贪心分组向量化 +
  位运算提矩形（单组 158~169ms → 118ms，输出逐位不变）；GIL 切换间隔下调，
  加载时视口最大顿挫 69.6ms → 33.1ms。

## 校验

- `pytest tests/`：177 项全绿（含 A/B 模式逐面一致性）。
- Java ↔ Python：`tests/fixtures/*` 逐字节对拍（含 MCC1 v2 / MCM1 v2）。
- 实机验收：1.21.1 + Fabric 0.17.2 + Ultramarine 0.6.1（518 方块世界）。
