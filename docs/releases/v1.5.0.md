# v1.5.0 摄像机距离优先 + 区块更新策略 + 常见区块

> 本版重点：路线图新一轮 R9–R11 全部落地——加载顺序按摄像机距离优化、
> 区块更新有了完整的开关/事件驱动/手动/白黑名单策略、可钉选"常见区块"
> 不被卸载；并修复一批**首次在真实游戏里暴露**的缺陷（其中"版本追踪
> 从未生效"影响最大）。

## 新增

- **R9 按摄像机距离优先**：锚点跨组移动时按新位置重排加载队列、就绪区块
  按距离应用——近处先上屏（网络抖动时远组先完成也不插队）。派发保持并行、
  不做串行化，**吞吐无损**。面板可开关。
- **R10 区块更新策略**：
  - **自动更新总开关**（两种模式）；
  - **事件驱动**（控制模式）：模组维护**全局世界修订号**
    （`GET /api/worldrev`，任一方块状态变化 +1），插件以**亚秒级**间隔
    只取这一个整数（开销≈0），变化才重载受影响区块——覆盖挖掘、放置、
    爆炸/活塞、作物生长、水与岩浆流动、命令 `setblock` 等一切**改变
    方块状态**的操作（不含箱子内容之类的方块实体数据）。旧模组自动回退
    常规版本轮询；
  - **存档模式自动更新**：按存档文件变更戳（`.mca` 的 mtime+size）比对，
    外部保存后自动失效缓存并重载；「立即刷新」修复旧版不清缓存的缺陷；
  - **更新白名单 / 黑名单**（组级，随 `.blend` 保存）：白名单强制更新
    （总开关关闭也更新）、黑名单永不自动更新（黑名单优先）。
- **R11 常见区块（钉选）**：选中的区块组不被主动卸载，移出加载半径后仍在
  场景；「自动预载」在连接时与「卸载全部」后自动拉回；超过 64 组告警内存。
- 面板新增「区块管理」框（常见区块 / 白名单 / 黑名单，均对**选中对象**操作）
  与「事件轮询间隔」等选项。

## 修复

- **版本追踪 / 事件驱动此前从未在真实游戏生效**：`mcbridge.mixins.json`
  把 mixin 清单写在了 `"*"` 键下——Mixin 配置没有这个键，被静默忽略，
  实际注册数量为零（`defaultRequire: 0` 又掩盖了失败）。改用 `"mixins"`。
  此前只有模拟服务器验证过（sim 不走 mixin），真实环境一直未被覆盖。
- **更新后内容不变**（"有刷新迹象但方块没更新"）：版本变更重排队后
  `ChunkStore` 的 payload 缓存从未失效，重新网格化用的还是旧数据。
  现在版本变更/存档变更戳时清理组内缓存，「立即刷新」清空全部缓存。
- **面板开关连接后不生效**：`Params` 只在连接时构造一次，之后从不回读
  面板值——关闭"自动更新"仍会继续更新。现在每 tick 同步运行时策略。
- **区块无法加入名单**：真实 Blender 把 `obj["mcb_key"]` 的 dict 转成
  `IDPropertyGroup`（不是 `dict` 子类），旧代码的类型判断必然落空。
- **面板下半部整体消失**：给「事件驱动更新」用了 Blender 4.5 不存在的
  图标名 `LIGHTNING`，面板绘制到该行抛异常，其下所有内容不再绘制。
- **活塞等"整块但有朝向"的方块贴图错乱**：`_is_full_cube` 只判"几何占满
  整格"，活塞（单元素 16³ + 6 面）因此被当成普通完整方块走程序化立方体
  路径——朝向与面 rotation 全丢，活塞头贴图（在模型 -Z 面）被按"+Y=top"
  挑错，表现为"未推动活塞水平放置时 UV 错乱"。新增 `_is_simple_cube`
  （4 侧贴图一致 + 无 face rotation 才允许程序化路径），同类的熔炉/
  工作台/观察者/发射器一并修正；石头/原木等 4 侧一致的方块路径不变。
