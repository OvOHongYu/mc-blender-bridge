# v1.4.0 发光方块（R6）+ R7 收官 + 画定位定案

> 本版重点：发光方块在 Blender 里自发光（Cycles 可真实照亮场景）、
> 面板进度条与残留对象处理、GitHub Actions CI/CD、画定位实测定案。
> 至此路线图 R4–R8 全部条目完成。

## 新增

- **R6 发光方块自发光**：亮度 > 0 的方块自动追加 Emission 节点并 Add 到
  Principled——萤石/岩浆/海晶灯/火把/点亮的红石灯等效原版点光源，
  Cycles 下真实照亮场景，夜景/洞穴不用再手动布光。
  - **改进自发光**（默认开）：发光颜色先经对比度(2.1)与饱和度(0.9)处理，
    只让贴图高光部分主导发光（强度系数自动 ×0.175，默认 4.0 → 0.7），
    避免原版式整块均匀泛光的观感；
  - **自发光总开关**与**自发光强度**倍率（默认 4.0，改动即时生效——
    就地缩放已有材质的 Strength，无需刷新）；
  - **两种可叠加的发光筛选策略**：亮度属性（逐状态精确，含模组方块）与
    ID 关键词（lamp/candle/lantern/torch/glow/fire/lava… 整词命中按满亮度
    发光，兜底模组未声明亮度属性的"灯"类方块；可能有少量误伤，可关）。
- **R7 面板进度条**：预热/首载时面板显示"加载中/预热中 x/y (z%)"（区块组），
  状态栏同步原生进度条，全部就绪自动消失。
- **R7 load_post 残留对象处理**：打开含 `MCB_` 区块对象的 .blend 时面板提示
  数量，一键**转为静态保留**或**全部清除**；切换文件自动重置失效连接
  （按文件路径变化区分 memfile 撤销，undo/redo 不误断连接）。
- **R7 CI/CD**：GitHub Actions——push/PR 跑 pytest 全量 + 夹具再生对拍 +
  Java 构建与跨语言一致性对拍 + 发行包打包 artifact；打 `v*` tag 自动发版
  （内置 GITHUB_TOKEN，无需 PAT）。

## 修复

- **画（painting）定位**（R5 定案）：实机对拍发现画面整体向上偏移 h/2
  （与画高成正比、与宽度无关、控制/存档模式一致）——定案 MC 实体
  `Pos` = 画面**中心**（初版误按底边中点锚定），修复为
  底边 = Pos.y − h/2。多尺寸四面墙实测全部对齐。
- **存档模式染色蜡烛不自发光**：内置亮度表补齐 16 色蜡烛/蜡烛蛋糕
  （与素色蜡烛同公式 `3×数量`，点燃才亮）。
- `/api/blocks` 新增 `lights` 逐状态亮度表（`state.getLuminance()`，
  1588 条），键与调色板状态名同构（`Property.name` 序列化）。

## 校验

  画中心对齐回归）。
